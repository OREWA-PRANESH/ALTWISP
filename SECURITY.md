# Security policy

Use the latest release. Older releases have no guaranteed security support.

Use GitHub's **Report a vulnerability** in the Security tab if private reporting
is enabled. If unavailable, open an issue requesting a private reporting channel
without exploit details, credentials, audio, transcripts, or sensitive information.

Through the private channel, provide affected versions, impact, reproduction steps,
and a minimal sanitized example. Allow maintainers time to investigate. No fixed
response time is promised.

API keys and local history are not encrypted by ALTWISP. Protect your Windows
account. Cloud mode sends audio/text to a third party. Read
[privacy details](docs/PRIVACY.md) before sharing diagnostics.
