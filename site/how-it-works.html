FROM VOICE TO TEXT

How it
works.

ALTWISP is a Windows dictation app that runs in the tray. It records when you use its shortcut, turns speech into text, and places that text in the app you were already using.

01 / THE FLOW

One shortcut.
Three steps.

Keep the text field you want to use active while ALTWISP works.

01

Start recording

Click a text field, then press and release Ctrl + Windows. A small floating orb shows microphone activity without taking focus.

02

Speak and stop

Speak naturally. Press and release the same shortcut again to stop. ALTWISP sends the recording to your chosen transcription engine.

03

Use your words

ALTWISP attempts to paste the result into the original app. If the target changed or blocks pasting, open the dashboard to copy the latest transcript.

02 / YOUR CHOICE

Choose where speech
becomes text.

Change the engine in Settings. Your choice determines whether recorded audio leaves your computer.

GROQ / CLOUD

Connected speed.

ALTWISP sends recorded audio to Groq for transcription. This mode needs an internet connection and your own Groq API key.

Optional AI polish can also send the recognized text to Groq to refine the writing style.

WHISPER / LOCAL

On-device recognition.

ALTWISP runs Whisper on your PC. The model needs an initial download; afterward, transcription can run offline.

Local mode disables cloud AI polish. Speed depends on your hardware and the model you choose.

DATA PATH

Transcript history, personal dictionary, snippets, settings, and your API key are stored on your computer. The history database is local; Groq mode still sends audio, and optional cloud polish sends text. You can turn off future history saving in Settings.

03 / EVERYDAY USE

Built for the way
you write.

The dashboard gives you control without interrupting dictation.

01 / HISTORY

Find recent words

Review and copy saved transcripts. Clear the history whenever you want.

02 / DICTIONARY

Get names right

Add spoken phrases and replacements for product names or terms you use often.

03 / SNIPPETS

Say less

Turn a short spoken trigger into a longer piece of reusable text.

04 / MICROPHONE

Check your input

Test and select a microphone in Settings when Windows uses the wrong device.

04 / GET STARTED

Ready on
Windows.

ALTWISP supports Windows 10 and 11 on x64 PCs with a working microphone.

Download the Setup EXE, install it, and allow desktop microphone access in Windows. Choose Groq or local Whisper in Settings, then try a short dictation in Notepad. The GitHub repository is currently private, so release downloads require authorized access.
